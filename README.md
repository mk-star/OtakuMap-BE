## 프로젝트 소개
오타쿠 맵 (OTAKU MAP)은 애니메이션 관련 이벤트와 성지순례 명소 정보를 지도 기반으로 제공하며,  <br/>
여행 후기 공유와 루트 저장/커스터마이징 기능을 통해 팬들의 여행 경험을 풍부하게 만들어주는 서비스입니다.

<br/>

## 주요 기능
### 🎟️ 애니메이션 관련 이벤트 정보 확인
진행 중인 애니메이션 이벤트 정보를 한눈에 확인할 수 있습니다.

### ✍️ 여행 후기 작성 및 공유
사용자들이 여행 후기를 작성하고, 다른 사용자와 공유할 수 있습니다.

### 🗺️ 지도에서 명소와 이벤트 확인 가능
애니메이션 관련 이벤트 및 성지순례 명소를 지도에서 확인할 수 있습니다.

### 📌 명소, 이벤트 저장 기능
관심 있는 명소나 이벤트를 저장하여 나중에 편리하게 다시 확인할 수 있습니다.

### 🛠️ 여행 루트 커스터마이징  
다른 사용자의 여행 루트를 참고해 자신만의 일정으로 수정하고, 나만의 맞춤형 여행 계획을 세울 수 있습니다.

<br/>

## 기술 스택
- Tech Stack
  - Spring Boot, Spring JPA, Querydsl, Spring Security, JWT
- DB
  - AWS RDS (MySQL)
- DevOps
  - AWS EC2, Github Actions, Docker

<br/>

## 담당 업무
- 회원 관리 기능
- 한 줄 리뷰 UD
- 저장한 이벤트 RUD
- 루트 CRU
- 장소 CD
- Github Actions과 Docker을 활용한 CI/CD 구축
- AWC ACM과 ELB(ALB)를 활용한 HTTPS 적용
